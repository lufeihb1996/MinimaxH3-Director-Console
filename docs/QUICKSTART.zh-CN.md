# 快速开始 — 15 分钟做出第一个项目

[English](QUICKSTART.md) | [简体中文](QUICKSTART.zh-CN.md)

前提是已经有一台能访问的 ComfyUI（怎么起看主 README 里的 Colab 脚本）。没有也能走完第 1–4 步，只是生成时会显示 `offline`。

## 0. 启动

```bat
start.bat
```

浏览器会自动打开 <http://127.0.0.1:18080>。然后打开右上角 **设置**：

| 字段 | 填什么 |
|---|---|
| `comfy_url` | 你的隧道域名，例如 `https://my-gpu.example.com` |
| `pika_url` | 没有独立 Pika 服务就留空 |
| `fps` | `24` 即可 |

点 **测试连接**，状态灯变成在线即可。

## 1. 建项目

1. 点左上角 **项目** 旁的 `＋`。
2. 起个名字，比如 `我的第一个短片`。
3. 点 **新建场景**，命名 `场景 1`。

## 2. 生成一张参考图

1. 顶部切到 **生图工作台**。
2. 选 `场景 1`，槽位 **Ref1**。
3. 模型选 `moss_image_5b`，比例 `9:16`，提示词例如
   *黄昏河边站着的年轻女性，电影感打光*。
4. 点 **生成** → 等结果 → 点选 → **应用**。

Ref1 就成了这个场景 CUT 镜头的默认人物图。

## 3. 建一个镜头

1. 切回 **视频导演台**。
2. 点 **新建分镜**。
3. 设置：

| 字段 | 值 |
|---|---|
| 模式 | `CUT`（吃参考图） |
| 视频模型 | `b15_49` |
| 秒数 | `5` |
| 提示词 | *她转头看向镜头，头发被风吹动* |
| 二采 | 第一次先关掉 |

## 4. 生成

点镜头上的 **生成**。应该能看到：

- 状态从 `QUEUED` → `PREPARING` → `RUNNING`
- 进度条跟随 ComfyUI 节点流推进
- 终端面板滚动显示远端日志

本机不会下载任何模型，只上传参考图并轮询 ComfyUI。

## 5. 看结果

跑完后状态是 `DONE`，出现版本 `shot_0001_v1.mp4`，可以直接内嵌播放。不满意就改提示词再点 **生成**，会生成 `v2`，`v1` 保留。

## 6. 加音频（可选）

- **音频工作台 → 生成歌曲**（YuE2）或 **上传音频**，然后点 **分析**。
- 分析依赖 `audio_analysis/` 环境；没装这一步会报错，可以完全跳过音频。

## 7. 合并

- **播放本场景**：合并当前场景已完成的镜头。
- **合并全剧**：在 `projects/project_NNN/` 里产出 `project_NNN_master.mp4`。

两个入口在顶栏和场景工具栏上。

---

## 出问题怎么办

| 现象 | 处理 |
|---|---|
| 状态灯一直 `offline` | `comfy_url` 填错、隧道掉了、或 Colab 运行时被回收——重跑 Notebook |
| 提示 `FFmpeg not found` | 装 FFmpeg，把 `bin` 加进 `PATH`，重开终端 |
| 镜头卡在 `QUEUED` | GPU 槽位被别的任务占着，看队列条和终端面板 |
| 生成失败但没细节 | 打开该镜头的终端面板，通常最后一行业远端日志就是原因 |
| 二采勾选框是灰的 | 该模型不支持（`pika_h3` 有自己的一套） |

## 数据存在哪

| 内容 | 位置 |
|---|---|
| 项目数据 | `data/studio.db` |
| 图片 / 视频 / 音频 | `projects/project_NNN/` |
| 每次任务冻结的输入 | `projects/project_NNN/scene_NNN/shot_NNNN/inputs/<id>/` |
| 本地服务日志 | 启动它的终端（uvicorn 输出） |

备份就是 `data/` 和 `projects/` 一起拷——两边用绝对路径互相引用。
