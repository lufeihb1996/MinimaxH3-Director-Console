# 数字人口播与访谈

共用操作边界见 [AGENTS.md](../../../AGENTS.md)，模型、API 与音频实现见 [技术速查](../../../AI_QUICK_CONTEXT.md)。本流程使用配音工作台和支持外部原声锁口型的 B15；Pika 当前不支持这条口播驱动流程。

## 按需读取

- 写配音稿时读 [音频稿规范](references/audio-script-spec.md)。
- 写新母图时读 [MOSS 生图 Skill](../moss-image-realism/SKILL.md)；已有固定母图优先复用。
- 写视频提示词时参考 [H3 格式与模板](../minimax-h3-ref-animator/SKILL.md)，但采用本文件的固定机位规则。
- 音频切片预检、抽帧验收或后期包装时读 [制作与交付参考](references/production-notes.md)。不做包装时无需加载 Remotion 细节。

## 先确认内容与人物

- 用户给截图、新闻或零散材料时，先核实人物、原话、数据来源和前后因果；不只把截图念出来。虚构内容与已确定的稿件按用户要求处理。
- 新拟口播先展示主题/故事主线、关键事实与内容顺序、带说话人和情绪标签的 `script_text`，用户确认内容后再保存。已有明确确认和授权的内容直接继续，不重复要求确认。
- 时长优先遵循用户要求；未指定时可先写约一分钟版本。字数只是估算，分句与实际长度按音频稿规范和生成后的音频验收。
- 访谈默认主持人使用[阿岚资产配置](../../../config/personas/host_alan/persona.json)和[固定母图](../../../config/personas/host_alan/host_ref1.png)。身份、服装、seed、历史参数和音色 ID 只在该配置维护。
- 优先上传复用同一张母图；不要按 seed 重生成后宣称脸完全一致。新主持人或换人设另建 persona，不覆盖固定资产。访谈 Ref1 为主持人、Ref2 为嘉宾。
- 参考音色优先选约 8–12 秒清晰访谈干声；带 BGM 或混响的影视片段先处理，不能直接当成干净参考。

## 从配音稿到带词分镜

1. **保存配音任务**：通过 `POST /api/projects/{pid}/voice-jobs` 一次保存已确认的 `title`、`script_text` 和 `speakers` 绑定。改稿新建任务，保留旧音频对照；不直接写 SQLite。
2. **准备母图**：保存四槽配置或上传固定资产。核对图中实际房间、麦克风与光源方位，不把主持人桌面母图未经检查就当作双人扶手椅场景。
3. **生成并验收音频**：按授权由用户或代理触发配音，试听语音和静音。确认配音成为当前项目音频；已有歌曲/外部音轨时不能假设自动覆盖，必要时显式“设为本项目音频”。口播不通过歌曲工作台重新上传配音。
4. **分析与预览**：完成项目音频分析后，检查 `GET /api/projects/{pid}/audio/timeline` 的所有行 `aligned_ratio == 1.0`。调用 `shots/from-timeline` 的 `dry_run=true`，检查实际切点、短镜与非静音告警。
5. **一次带词建镜**：按预览结果写完整 `initial_shots`，包含每镜标题、mode、prompt、dialogue 和所需模型；使用同一组规划参数 `dry_run=false` 保存。数量按实际预览镜数，不能按稿件行数猜；遇到 `PLAN_CHANGED` 重新预览。
6. **交接生成**：读回全部镜头、参考图、模型和音频时间，完成制作参考中的首镜音频预检，再按授权生成。排队前完成模式与素材变更，避免已冻结镜头缺图。

普通建项可用 `quick_seed_project.py` 创建项目/空场景；口播时间点与镜头由 `from-timeline` 产生，不手写逐条循环建镜或按字数比例估算切点。

## 口播镜头规则

- 每个生成段只写 `[Shot 1]`，使用 `The camera holds a static shot.`；不在句中切 `[Shot 2]` 或突然换景别。
- CUT 用六段式 Ref2VA，CONTINUE 用三段式 I2VA；人物、服装与实际参考图一致。MV 已有纯人声驱动，不另塞一套 `<d>` 台词。
- 单人连续口播默认每 4 镜一段：段首 CUT、段内 CONTINUE；长段落的下一段首 CUT 换景别，仍保持同一人物、房间方位和固定机位。
- CONTINUE 从上一镜真实末帧开始；段首 CUT 使用已保存母图。不能把四槽图传给 CONTINUE，也不能用提示词强行补首帧中没有的嘉宾。
- 说话镜让脸清晰稳定，保留自然眨眼、轻微手势。字幕和包装在后期处理，需要无字幕底片时明确禁止画内文字。

## 双人访谈的额外规划

默认自动分镜按分组设置模式，不保证识别说话人；在保存 `initial_shots` 时按下表明确覆盖：

| 内容变化 | 模式与画面 |
|---|---|
| 同一人继续说、机位不变 | CONTINUE |
| 换说话人 | CUT，重新建立对应人物的单人构图 |
| 单人转双人同框 | CUT，不从单人末帧直接续出第二个人 |
| 长段落重新建立景别 | CUT，并核对实际房间左右关系 |

- 双人镜用于开场、必要的互动和收尾；90 秒访谈可先按约 3–4 个同框镜规划，再依据内容调整。
- 单人镜明确画面只包含当前说话人，另一人在画外；双人镜明确谁说、谁闭嘴倾听。
- 主持人与嘉宾的视线方向形成同一条轴线；根据实际母图确定左右，整片不反轴。
- 保存后检查所有 CUT 继承了实际需要的 Ref1/Ref2/场景图，所有 CONTINUE 均有可接续的上一镜，prompt 与对应台词一致。

## 验收与交付

- 音频稿格式、静音与行对齐按音频稿规范验收，不能用 DONE 替代试听。
- 至少检查开场、双人同框、段首 CUT 和一个 CONTINUE 接缝：脸、衣服、房间轴线、听者嘴型、手部重影与吞字。
- 素片通过后合并场景/全剧。需要后期时再使用制作参考中的 Remotion 流程，保留原素片。
- 对外画面沿用项目保密约定：不展示真实底层模型名、内部参数、seed、脚本与制作流程。用户明确要求的技术说明另按其用途处理。
